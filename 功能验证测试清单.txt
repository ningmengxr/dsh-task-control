dsh-task-control 插件 - 功能验证测试清单（v9）
================================================

⚠️ 先做：硬刷新 Ctrl+Shift+R 加载最新 bundle。
⚠️ 本次改动：新增【急停】按钮（红色底白字，位于「拍一下deepseek」左侧，order 80）：
   一键强制终止当前任务（杀进程 + cancel），解决"下载进行中想换源却停不下来"的无助场景；
   按钮文案可在设置卡自定义（默认"急停"）。
⚠️ 本次改动：下载类任务（curl/wget/Invoke-WebRequest/-o/OutFile）**无论是否超时**，
   点「拍一下deepseek」都会先查宿主状态：
   - 下载进程仍活跃 → 输出"正在下载 xxx，进度 xx%，下载仍在继续，请耐心等待"
     （百分比 = 下载文件大小 / URL 的 Content-Length，宿主发 HEAD 获取；
      拿不到总大小时退回"已下载 x.x MB"）
   - 下载进程已退出 → 输出"下载出现异常中断…" + 【强制终止】按钮
   - 非下载类工具调用超 10 分钟才判定"疑似卡死"

【测试 ⓪：未运行判断】
  - 在任务空闲（没有进行中的任务）时点「追加条件」
    → 期望：弹出提示"当前没有正在运行的任务"（居中圆角弹窗）
    → 期望：任务不被暂停、不出现输入弹窗、聊天里不出现任何"继续"/条件消息

【测试 ⓪⓪：急停按钮】
  - 确认三个按钮顺序：急停(红) | 拍一下deepseek | 追加条件（急停在最左，红底白字胶囊）
  - 任务空闲时点「急停」→ 应提示"当前没有正在运行的任务"（不弹确认）
  - 下载/安装进行中（如 pip install torch 或 curl 大文件）点「急停」
    → 期望【防误触】：先弹警告"如果现在急停会导致下载任务丢失，重新启动后需要全部重新下载"
    → 期望：确认按钮【灰色禁用】，勾选"我了解急停会导致下载进度丢失，仍要急停"后才可点
    → 点【确认急停】→ "已急停：强制终止了 N 个进程，任务已停止" → 任务【立即停止】
    → 点【取消】→ 弹窗关闭，任务继续，不执行急停
  - 设置卡应含「急停按钮文案」项（改文案立即生效）

【测试 ①：检测按钮（"拍一下deepseek"）】
  - 任务空闲时点它   → 应弹出"任务正常，无异常"
  - 任务运行时点它   → 应弹出"任务正在运行中，暂未出错"
    （若正在执行工具，会附带"（正在执行：工具名）"）
  - 任务出错时点它   → 应弹出"任务出错：<错误信息>"
  - 卡死识别（非下载）：工具调用超 10 分钟未返回 → "疑似卡死：工具X已运行X分X秒" + 强制终止按钮
  - 【新增】下载中检测：让 agent 执行一个慢速下载（如 curl 下载大文件，或
    `Start-Sleep -Seconds 700` 配合下载命令），超过 10 分钟后点「拍一下deepseek」
    → 若下载进程仍在 → 应弹出"正在下载 xxx，已下载 x.x MB，下载仍在继续，请耐心等待"
      （**不**判定卡死，**不**出现强制终止按钮）
    → 若下载进程已退出（如手动 kill 掉 curl）→ 应弹出"下载出现异常中断…" + 强制终止按钮
  - 强制终止：点击【强制终止卡住的任务】→ "已强制终止 N 个卡住的进程，任务正在停止…" → 任务立即停止

【中心测试：追加条件 - 20 秒慢速任务（故意不给路径）】
------------------------------------------------
测试任务（直接发给 agent，注意：不指定保存路径）：
  "请先执行 Start-Sleep -Seconds 20 模拟一个耗时任务，然后创建文件 result.txt，
   内容为"任务完成"，保存到你默认的工作目录"

操作步骤：
  1. 发出上面的任务（不含路径），agent 开始 20 秒等待
  2. 在等待期间（任务运行中）点「追加条件」
     → 期望：任务【立即暂停】
     → 期望：弹出居中圆角弹窗，顶部有"打开此窗口时程序会暂停"
  3. 输入："输出到E盘的deepseek文件夹里" → 点【确定】
     → 期望：agent 停止原任务，并按新条件重新执行（等待 20 秒后在 E:\deepseek 创建 result.txt）
     → 期望【方案 B】：聊天里【不出现】"补充条件：…"用户气泡；
       只出现一条低调的上下文提示行（ContextInjectionRow，如灰色小字"补充条件：…"）
  4. 再测一次：点「追加条件」→ 打开弹窗【不输入】→ 直接关闭（或按 Esc）
     → 期望：agent 恢复原任务（20 秒后 result.txt 出现在原默认目录）
     → 期望【方案 B】：聊天里【不出现】"继续"用户气泡；只出现低调上下文提示行

【测试 ③：设置卡】

    检测·出错输出 / 检测·运行中输出
  - 改其中一项 → 观察是否生效
